# Audio

Recorded audio for the call sims. The calls are meant to be **heard, not read** —
there is no on-screen transcript.

- `quiet-hours-line.mp3` — the recording on the old Quiet Hours number,
  reached at `call-sim.html?n=quiet` (number 0163). Referenced as `QUIET_SRC`
  in `call-sim.html`. If the file is absent the call still connects and holds a
  room tone for ~16s, then ends.

Drop the file(s) here with the exact name(s) above. mp3 or m4a.
